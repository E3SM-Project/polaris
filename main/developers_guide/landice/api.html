landice

Landice()

The collection of all tasks for MALI

Landice.configure(config, steps)

Configure the component

Landice.build_model(config, machine)

Build MALI

get_build_albany(config)

Whether a MALI build should have Albany, from the albany option in the [build] config section

add_landice_tasks(component)

Add all tasks to the landice component

Tasks

dome

add_dome_tasks(component)

Add tasks for the dome test to the landice component

init.Init(component, resolution, indir)

A step for creating the mesh and initial condition for dome tasks

init.Init.run()

Run this step of the task

forward.Forward(component, init, velocity_solver)

A step for running MALI on the dome mesh

validate.Validate(component, step_subdirs, ...)

A step for comparing the outputs of two dome runs

validate.Validate.run()

Compare the variables in the outputs of the two steps

viz.Viz(component, init, indir[, forward_subdir])

A step for plotting the ice thickness and surface speed at the end of a dome run

viz.Viz.run()

Run this step of the task

smoke_test.SmokeTest(component, ...)

A dome task that runs MALI and plots the results

decomp.Decomp(component, velocity_solver, ...)

A dome task that makes sure MALI gives the same results on 1 and 4 tasks

restart.Restart(component, velocity_solver, ...)

A dome task that makes sure MALI gives the same results with one 2-year run and with a 1-year run that restarts from the first year of it

Model

MaliModelStep(component, name[, subdir, ...])

A step for running MALI

MaliModelStep.needs_albany

Whether the step uses a velocity solver from Albany

MaliModelStep.uses_gpus

Whether the step runs on GPUs

MaliModelStep.setup()

Request GPUs if the step uses them, then set up the command-line arguments

MaliModelStep.constrain_resources(...)

Request GPUs if the step uses them, then constrain the step's resources to those available

MaliModelStep.dynamic_model_config(at_setup)

Set the velocity solver, if one was given

Mesh

make_mali_mesh(in_filename, out_filename, ...)

Turn a culled planar MPAS mesh into a MALI mesh with the fields MALI needs, without needing a MALI build
