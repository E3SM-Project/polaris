polaris.e3sm.init.assemble.AssembleStep

class polaris.e3sm.init.assemble.AssembleStep(component, name, subdir, readme_package, readme_filename='README')[source]

A base step for materializing a staged tree of E3SM input files.

Product steps write only their own outputs, and a subclass of this step links them into ASSEMBLED_FILES at their E3SM-facing paths, so what is in the tree is described in one place rather than in every step.

A subclass declares the products it stages as input files in its constructor. Its run() calls this class’s run(), which rebuilds the tree from empty and stages the README, and then calls stage() and stage_partitions(). Staging happens at run time because the staged paths carry names, such as the creation date, that come from config options a person may change after setup.

__init__(component, name, subdir, readme_package, readme_filename='README')[source]

Create a new step.

Parameters:

  • component (polaris.Component) – The component the step belongs to.

  • name (str) – The name of the step.

  • subdir (str) – The subdirectory for the step.

  • readme_package (str) – The package the README staged at the top of the tree comes from. What a tree does and does not hold is particular to the workflow that stages it, so each supplies its own.

  • readme_filename (str, optional) – The README’s filename in readme_package.
