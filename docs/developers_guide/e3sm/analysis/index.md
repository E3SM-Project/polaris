# E3SM analysis (e3sm/analysis) component

The `e3sm/analysis` component holds tasks that analyze E3SM runs Polaris did
not set up, reading the output of every model in the run and of the
coupler. Its shared framework code is in `polaris.e3sm.analysis`.
